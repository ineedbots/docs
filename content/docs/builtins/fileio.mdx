Module for accessing, reading, writing and deleting files.

All operations will take place in the `scriptdata` folder. Your path will be prepended with `scriptdata/` if it doesn't have it already, so it doesn't matter if you include it or not. Which means all IO will take place inside of the `scriptdata` folder.

You cannot traverse upwards in directories. (`..`, `.`, `:`)

You can use forward slashes or backslashes, make sure to escape your backslashes.

IO uses the game's searchpaths, which means it will search in multiple directories in an order. For example: `<storage_path>/<fs_game>/` will be searched before `<storage_path>/main`, which will be searched if prior was not found, etc.

If the dvar `scr_allowFileIo` is disabled, all of these built-ins will script error stating that it is disabled.

All files are automatically closed when the map changes or restarts (fast_restart or loading a save).

All of these functions begin with `FS_`, so you can do a simple audit and search across a GSC codebase to see what IO operations it will do.
